기존 9개 단어에 15개 개념을 더해 총 24개를 한글 뜻 조각으로 펼치고 입법·행정·사법, 역할·방향에 연결합니다. 디자인은 선택한 2번 목업의 남보라 배경·기울어진 아이보리 카드·살구색 선택 버튼을 반영합니다. 처음 익힌 단어는 국회의원·국회의장·국무총리·국무위원·국무회의·대법원장·의원 내각제·내각 불신임권·의회 해산권입니다. 한자는 표시하지 않습니다. 마지막에는 기존 비교 5문제에 새 비교 4문제를 더한 9문제가 이어집니다.

교사가 설명하는 수업용입니다. 단어와 입법·행정·사법 버튼을 같은 화면에 두고, 뜻 조각은 카드 안에서 펼치거나 모읍니다. 기관 연결·역할·비교의 정답과 오답은 모두 모달에 표시합니다. 결과 모달은 자동으로 닫히지 않으며 `계속`, `다음 질문`, `다음 단어`, `다시 선택하기`로 진행합니다. 닫기·Escape로 카드에 돌아와도 선택과 결과가 유지되고 `결과 다시 보기`로 재확인할 수 있습니다. 본문 정답 배지·해설·채점 모션은 두지 않습니다. 완료 단어를 다시 선택하면 결과 모달에서 확인합니다. 모달 안의 Tab·Shift+Tab은 내부 버튼 사이를 순환하고, 닫으면 결과 열기 버튼으로 초점이 돌아갑니다. 단어와 뜻 조각은 유지되며 다음 단어를 누를 때 카드를 바꿉니다. 아래의 단어 버튼으로 순서와 관계없이 이동해도 각 단어의 진행 상태는 유지되며, 완료한 단어는 `다시 풀기`로 초기화합니다. 모든 선택은 일반 버튼이며 Tab·Enter·Space로 조작합니다. 선택과 결과는 테두리·문자·기호로 함께 표시하며, 동작 줄이기 설정을 지원합니다. 글꼴·이미지를 외부에서 불러오지 않고, 입력·완료 상태는 현재 페이지 메모리에만 남습니다. 새로고침하면 초기화됩니다.

결과 모달 디자인 개선(2026-10-25): 사용자가 지목한 정답 모달을 기존 카드의 남보라·아이보리·살구색에 맞춰 정리했습니다. 기관 연결 정답은 반복 질문·선택 문장·동일한 해설 대신 ‘단어 → 선택한 권력’을 큰 연결 카드로 보여 줍니다. 복수 정답은 각각의 권력 표지로 표시합니다. 이어진 역할 정답 수정 요청도 반영해 ‘단어 → 역할 답변’을 같은 카드로 표시하고, ‘기억할 연결’에 반복되던 해설은 제거했습니다. 질문은 답변 위에 작게 두어 권한의 대상이나 제도 특징을 묻는 문맥을 유지합니다. 작은 화면의 역할 카드는 단어·아래 화살표·답변의 세로 배치이며, 헌법재판소가 일반 법원과 별도라는 구분은 짧은 보충 설명으로 유지합니다. 비교 결과와 오답은 질문·선택한 답·연결 또는 재선택 힌트를 구분합니다. 다음·재선택 버튼은 모달 아래에 넓게 배치합니다. 결과 전용 스타일은 질문·힌트·완료 모달로 넘어가면 해제됩니다. 동작과 채점 규칙은 유지합니다.

모달 재검증: 기관·역할·비교의 정오답, Escape 후 선택 보존과 결과 재열기, Enter·Space 제출, Tab·Shift+Tab 순환, 비교 9문제 후 완료 모달 진입을 확인했습니다. 794px 화면에서 기관 연결 결과를 시각 확인하고, 320px 화면에서 복수 권력 표지와 비교 9문제 결과에 가로 넘침이 없음을 확인했습니다. 콘솔 오류·경고는 없었습니다. 실제 기기·교실 투사 검수는 미실시입니다.

역할 카드 추가 검증: 국회의원 역할 정답을 794 × 827에서 확인했습니다. 320 × 720에서는 국무총리·의원 내각제·국정 감사권·헌법재판소·헌법 소원 심판의 역할 결과 6개에 가로 넘침과 중복 해설이 없으며, 필요한 보충 설명이 표시됨을 확인했습니다. 역할 오답 재선택·Escape 후 재열기·키보드 제출과 비교 문항의 질문 보존도 확인했습니다.

질문·선택지 중앙 정렬(2026-10-25): 선택지가 가운데 선명하게 드러나게 해 달라는 요청에 따라 질문 제목을 가운데에 두고, 선택지 글씨를 상하좌우 중앙에 배치했습니다. 위아래 여백을 같게 하고 선택 표시는 오른쪽 위에 두어 글씨 위치가 달라지지 않게 했습니다. 확인 버튼도 힌트 버튼과 관계없이 모달의 정중앙에 놓입니다. 빈 힌트 영역은 숨기며 힌트를 켜면 중앙에 표시합니다. 짧은 세 선택지는 세 열을 유지하고, 공백을 뺀 글자 수가 8자를 넘는 선택지가 있으면 650px 이하에서 한 열로 넓게 제시합니다. 794px에서 제목·확인 버튼의 중심 오차 0px, 320px에서 긴 문장·두 선택지의 넘침 없음과 결과 전환·키보드 제출을 확인했습니다. 실제 기기 검수는 미실시입니다.

`뜻으로 나누기`는 같은 글자 요소와 글씨 크기를 유지한 채 약 0.55초 동안 뜻 단위 사이를 벌리고, 그 아래에 풀이를 드러냅니다. 풀이가 들어갈 만큼 카드가 아래로 늘어나며, `단어로 모으기`는 반대 방향으로 움직입니다. 풀이 글씨는 데스크톱 24px, 작은 화면 18px을 유지합니다. 기기의 동작 줄이기 설정에서는 즉시 펼치고 모읍니다.

기관·권한·국가 작용을 구별하여 질문합니다. 일반 기관은 소속을, 권한은 행사하는 쪽을, 헌법재판은 담당하는 국가 작용을 묻습니다. 의원 내각제와 대통령제는 관계를 맺는 두 권력인 입법·행정을 모두 선택한 뒤 구성 방식의 차이를 확인합니다. 내각 불신임권과 의회 해산권은 **권한을 행사하는 쪽**을 묻고, 다음 질문에서 대상을 확인합니다. 이름 앞의 기관을 권한의 주체로 취급하지 않습니다. 두 권한의 최종 결과에는 주체 → 대상의 권력과 기관을 함께 표시합니다.

### 교사용 설명과 모형의 범위

- 뜻 조각은 학습을 위한 풀이입니다. ‘국무’는 나라의 일이라는 말 자체이며, 그 글자만으로 행정부 소속이 증명되는 것은 아닙니다. 실제 기관의 역할에 연결해 확인합니다. 의원 내각제의 ‘의원’은 의회라는 기관, 국회의원의 ‘의원’은 사람을 뜻합니다.
- 국무총리는 대통령을 보좌하고 대통령의 명을 받아 행정 각부를 통할합니다. 의원 내각제의 총리와 우리나라 국무총리를 같은 지위로 설명하지 않습니다.
- 국무회의는 대통령·국무총리·국무위원으로 구성되며, 대통령은 의장, 국무총리는 부의장입니다. 국무회의는 중요한 정책을 심의합니다. 국무위원은 행정 각부의 장과 완전히 같은 개념은 아닙니다.
- 국회의장이 국무회의의 의장 또는 당연한 구성원인지 묻는 활동입니다. 특정한 회의의 배석 가능성 자체를 단정하지 않습니다.
- 국회의원·국회의장은 입법부, 국무총리·국무위원·국무회의는 행정부, 대법원장은 사법부의 법원에 연결합니다. 대법원장의 지위가 각 법관의 독립된 재판에 대한 지휘권을 뜻하지는 않습니다.
- 의원 내각제의 의회 다수파 지지·내각 구성·의회에 대한 정치적 책임과 불신임·해산은 교과서의 기본모형으로 표시합니다. 국가별 총리 임명권자·해산 절차·요건과 건설적 불신임 등 변형은 재현하지 않습니다. 대한민국 대통령에게 의회 해산권이 있다는 의미가 아닙니다.
